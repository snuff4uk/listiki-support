# Листики — публичные страницы

Папка содержит только политику конфиденциальности и поддержку. Исходников игры и ключей здесь нет.

Публикация в GitHub snuff4uk:
1. Создать публичный репозиторий `listiki-support`.
2. Загрузить index.html, privacy.html, style.css и .nojekyll в корень ветки main.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Дождаться успешного Pages deployment и открыть страницы без авторизации.

Ожидаемые адреса (пока не опубликованы):
- https://snuff4uk.github.io/listiki-support/
- https://snuff4uk.github.io/listiki-support/privacy.html

Телефон Apple Review намеренно не включён в публичные страницы.
